# ВУАЛЬ-v1 — многоуровневый протокол живого контакта Кординапс

**Статус:** стандарт дома, слово Дениса 24.10. 
**Область:** ЛЮБОЕ взаимодействие дома с живыми людьми наружу — отклики, чаты, письма, заявки, комментарии. 
**Суть:** перед тем как слово дома уйдёт живому человеку, оно проходит уровни. После — живая проверка.

---

## 0. Принцип

Слово дома наружу — это лицо дома. Любой текст, любое сообщение, любой ответ в чате проходит ВУАЛЬ. Не только отклики биржи. Промты приходят и уходят, провайдеры меняются — ВУАЛЬ живёт в коде и в кольце, ей не страшны чужие поломки.

## 1. Уровни ДО отправки (стоп-вуаль)

- **У0. Мусор-фильтр (код, не память):** текст проходит `otklik-lib.py` — `is_clean()` обязан вернуть True (приветствие, подпись, нет служебных маркеров, длина 300–5000). Не прошёл — не отправляется, точка.
- **У1. Редактор:** опечатки и грамматика; конкретика из ТЗ (названия, числа, термины заказчика); минимум одно доказательство чтения ТЗ; вопрос в конце; цена и срок названы явно; подпись.
- **У2. Контролёр:** красное (обещания сверх сил, серые схемы, «гарантирую доход»); юр-рамки НЕ встраиваем — юр-позиции формирует только юрист; нереальные сроки; демпинг; шаблонные повторы.
- **У3. Триада (везде, где уместно):** «мы именно этим направлением занимаемся» → «есть наработки/шаблоны, можем показать демо» → «поэтому готовы подвинуться в цене 10–20%». Заказчик ответил — делаем демо его задачи до оплаты. Если прямых шаблонов нет — честно: «собираем под ваше ТЗ, демо первой версии до старта оплат».
- **У4. Живость заказа:** карточка вскрыта — «выбран исполнитель»/«закрыт» = не стрелять, черновик в архив.

## 2. Уровни ПОСЛЕ отправки (эхо-вуаль)

- **У5. Живое эхо:** прочитать отправленное на странице глазами кода — текст совпадает с задуманным, мусора нет. Расхождение — «Редактировать отклик», замена чистым.
- **У6. Витрина:** пост-отчёт в группу-витрину: id · название · чек · срок + текст целиком. Владелец видит всё, что ушло наружу.
- **У7. Реакция:** замечание владельца в группе → правка + пересылка (пометка «🔄 ПЕРЕСЛАН по замечанию»). Ответ заказчика → демо его задачи.

## 3. Ответственность уровней

| Уровень | Кто | Где живёт |
|---|---|---|
| У0 мусор | код | otklik-lib.py |
| У1 редактор | кольцо | промт кольца |
| У2 контролёр | кольцо | промт кольца |
| У3 триада | кольцо | промт кольца |
| У4 живость | код+кольцо | вскрытие карточки |
| У5 эхо | код | проверка после |
| У6 витрина | демон | cron + дроп-папка |
| У7 реакция | живая сессия | группа |

## 4. Тесты

`tests/test_veil.py` — чистка мусора, триада в тексте, запрет юр-рамок, живость заказа. Запуск: `python3 tests/test_veil.py`. Все зелёные — ВУАЛЬ цела.

## 5. Закон

ВУАЛЬ не отключается. Новый канал связи с людьми (почта, мессенджер, биржа) — означает ВУАЛЬ в нём с первого дня. Дом, который не может пройти свою же вуаль, не говорит с людьми.
